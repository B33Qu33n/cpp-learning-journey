# 🎮 Number Master

A C++ number-guessing game where you challenge the computer to discover its secret number!

## 🕹️ How to Play

1. Run the program.
2. Enter your name.
3. Guess a number between 1 and 7.
4. Follow the hints to figure out the secret number.
5. Guess correctly to defeat Number Master!

## ✨ Features

- Randomly generates a secret number from 1 to 7.
- Gives higher-or-lower hints after incorrect guesses.
- Checks whether guesses are within the allowed range.
- Welcomes the player and responds to their guesses.
